# 출근부 용어집

출근부(`apps/commute`) 코드·이슈·문서에서 쓰는 말을 정리한다. 같은 것을 가리킬 때는 여기 적힌 말만 쓴다.

## 사용자

| 용어       | 코드 이름                        | 뜻                                                                                                    |
| ---------- | -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 근로장학생 | `worker` (API), `STUDENT` (역할) | 출근부로 근무를 신청하고 기록하는 학생. 화면 문구에서는 "근로학생"으로 줄여 쓴다                      |
| 관리자     | `ADMIN` (역할)                   | 근로장학생의 근무·신청·업무를 관리하는 직원                                                           |
| 역할       | `role`                           | 로그인한 사용자가 근로장학생인지 관리자인지. 서버가 로그인 응답으로 알려 주고, 화면에서 고르지 않는다 |
| 학교 메일  | `email`                          | `@konkuk.ac.kr`로 끝나는 메일. 로그인 아이디로 쓴다                                                   |

## 인증

| 용어        | 코드 이름             | 뜻                                                                                                                              |
| ----------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 로그인      | `login`               | 학교 메일과 비밀번호로 들어가는 것. 성공하면 역할에 따라 근로장학생은 학생 홈(`/`), 관리자는 관리자 홈(`/dashboard`)으로 간다   |
| 승인 대기   | `PENDING_APPROVAL`    | 회원가입은 했지만 관리자가 아직 승인하지 않은 계정. 로그인할 수 없고, 로그인하면 승인 대기 화면(`/pending-approval`)으로 보낸다 |
| 로그인 실패 | `INVALID_CREDENTIALS` | 메일이 없거나 비밀번호가 틀린 경우. 둘을 구분하지 않고 같은 문구로 안내한다                                                     |
| 페이지 보호 | —                     | 로그인하지 않은 사용자나 역할이 맞지 않는 사용자를 다른 화면으로 보내는 것. 로그인 상태를 어디에 저장할지와 함께 따로 다룬다    |
| 로그인 유지 | —                     | 브라우저를 닫아도 로그인 상태가 남는 것. 페이지 보호와 함께 따로 다룬다                                                         |
